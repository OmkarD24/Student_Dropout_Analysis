# Student Dropout Analysis

### Student Dropout Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on analyzing student data to identify dropout patterns and predict students who may be at risk of leaving their education. It uses Exploratory Data Analysis (EDA), data preprocessing, feature engineering, and machine learning classification algorithms to generate meaningful insights and support better educational decision-making.

## 🎯 Objectives

- Analyze student academic, demographic, and socioeconomic data.
- Identify patterns and factors associated with student dropout.
- Perform data cleaning and preprocessing.
- Explore relationships between different student attributes.
- Build and compare machine learning classification models.
- Identify important features influencing student outcomes.

## 📊 Dataset Information

- **Total Records:** 4,424 students
- **Total Features:** 37 columns
- **Target Variable:** Student Outcome

**Target Categories:**
- Dropout
- Graduate
- Enrolled

The dataset includes information about student demographics, academic performance, previous qualifications, financial status, course details, and socioeconomic indicators.

## 🔍 Exploratory Data Analysis (EDA)

The project explores the dataset through different visualizations:

- Student outcome distribution.
- Age distribution of students.
- Gender-wise student outcomes.
- Course-wise student enrollment.
- Correlation analysis of independent features.
- Feature importance analysis.

## ⚙️ Data Preprocessing & Feature Engineering

The following techniques are covered:

- Handling missing values.
- Encoding categorical variables.
- Scaling numerical features.
- Principal Component Analysis (PCA) on curricular unit features.
- Train-test splitting for model evaluation.

## 🤖 Machine Learning Models

Five classification algorithms were implemented and compared:

1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier
4. Support Vector Machine (SVM)
5. K-Nearest Neighbors (KNN)

## 📈 Model Performance

The following accuracy scores are reported in the model comparison chart:

| Algorithm | Accuracy |
|---|---:|
| Decision Tree | 83.2% |
| Random Forest | 82.8% |
| Logistic Regression | 81.0% |
| SVM | 80.9% |
| KNN | 79.2% |

**Best Performing Model:** Decision Tree Classifier (83.2%)

## 📌 Key Insights

- Approximately 32.1% of students in the dataset belong to the dropout category.
- Academic performance and curricular unit indicators are important factors in understanding student outcomes.
- Age and gender distributions reveal differences across student outcome categories.
- Financial and personal circumstances are considered relevant factors in dropout analysis.
- Decision Tree achieved the highest accuracy among the evaluated models.
